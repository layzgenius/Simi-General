Cyanite Alternatives & Spotify Quota Workarounds

A complete guide to music audio analysis APIs for indie developers — covering emotional imprint matching, audio features (energy, valence, BPM), and how to survive Spotify's API lockdown.

Date: June 5, 2026 Context: Simi iOS music discovery app Mode: Standard deep research Sources: 15+ verified

Executive Summary

Spotify's double blow — deprecating audio features in November 2024 and locking extended quota behind 250k MAU in May 2025 — has effectively closed the door on indie developers relying on their API. For a vibe-matching app like Simi, this is a real problem, but a solvable one.

The best path forward is a layered strategy: Cyanite.io (or Bridge.audio) for deep emotional analysis, Musicae.io's Extended Audio Features API as a near-perfect Spotify drop-in replacement, and Last.fm for free tag-based similarity. For Simi specifically, Cyanite is the closest match to the core "emotional imprint" philosophy — it's the only API explicitly designed around musical mood and emotion rather than just technical features.

A secondary finding: Lee Martin (the author of the spotify.leemartin.com report you found) specifically names Cyanite as his recommended Spotify audio features replacement, validating this direction.

The Spotify Problem — What Actually Happened

⚠️ Two separate blows, 6 months apart November 2024: Spotify deprecated /audio-features, /audio-analysis, /recommendations, and /artists/{id}/related-artists for new apps. May 2025: Extended quota mode now requires a legally registered business with 250,000 MAU minimum — making it unreachable for solo developers.

The leemartin.dev State of Spotify Web API Report 2025 puts it bluntly: "250,000 MAUs. This means that you need to have a massively successful app before seeking an integration with the Spotify Web API." It's a catch-22 — you can't get access until you've already grown, but you can't grow without access.

For Simi, which currently uses Spotify links as input and relies on audio features for emotional matching, this means two things need solving: (1) getting audio feature data without Spotify's restricted endpoints, and (2) considering whether to reduce reliance on Spotify as the primary source of truth entirely.

What the leemartin.com report specifically recommends

Lee Martin's report is worth reading in full. For the audio features gap specifically, he writes: "I've been eyeing Cyanite as a potential alternative to Audio Features. Cyanite's business is analyzing the emotions of music and offers all of the measurements the Spotify Web API previously provided alongside even more data." He also recommends the iTunes Search API for basic metadata lookup (no auth required) and Apple Music / MusicKit for playback and playlist creation.

Category 1 — Spotify Drop-in Replacements

These restore the exact Spotify endpoints that were deprecated — same JSON format, same field names. Minimal code changes required if you're already using Spotify's API structure.

Musicae.io — Spotify Extended Audio Features API
Top Pick New 2026 RapidAPI

Built specifically because there was no stable Spotify audio features replacement. Mirrors Spotify's exact request/response format — literally a drop-in replacement. Restores all the deprecated endpoints.

  • Restores /audio-features, /recommendations, /related-artists
  • Identical JSON response format to Spotify (valence, energy, danceability, tempo, key, etc.)
  • No OAuth / no 403 errors / no quota restrictions
  • Sub-second response times
  • Also has "DJ Track Audio Analysis API" with deeper scores: dance_floor, chill, aggressive, hype, groove, peak_time
  • Available on RapidAPI (tiered pricing)
  • Relatively new (launched 2026) — maturity/longevity unproven
  • Available through RapidAPI only — third-party dependency
Free tier via RapidAPI (limited calls) → paid tiers
For Simi: Best option if you want to keep your current Spotify-style data model with zero refactoring. The DJ Analysis API's emotional scores (chill, hype, groove) align well with Simi's vibe-matching goals.

Category 2 — AI Music Intelligence APIs (Cyanite Alternatives)

These go beyond raw audio features — they use AI to understand emotional content, scene context, and sonic similarity. Closest to Simi's core "emotional imprint" concept.

Cyanite.io
Best for Simi Free test tier

The incumbent and most established AI music analysis API. Explicitly designed around the emotional content of music — not just technical features. Lee Martin specifically recommends it as his Spotify audio features replacement.

  • AI-generated mood, energy, genre, BPM tags
  • Similarity Search — matches tracks by sound, vibe, and era
  • Natural language search ("upbeat late-night indie pop")
  • Valence, arousal, emotional quadrant analysis
  • Upload your own audio OR search existing catalog
  • GraphQL API
  • Free tier available to test
  • Can struggle with low-quality audio files (demos)
  • Pricing scales up for catalog-level volume — not cheap at scale
Free test tier → contact for paid plans
For Simi: The strongest philosophical match. Cyanite's approach to emotional quadrant analysis (valence × arousal) is essentially what Simi's Vibe Map is already doing. Deep integration could unlock the "emotional imprint" layer that makes Simi unique vs. generic music apps.
Bridge.audio
Enterprise lean

AI auto-tagging API validated by ~20 years of musicologist expertise. Highly detailed, consistent taxonomy for genre, mood, vocals, and instrumentation. Designed for music libraries and sync agencies at scale.

  • AI-powered mood, genre, vocal, instrumentation tags
  • Curated thesaurus refined by musicologists over 20 years
  • Webhook delivery for async batch processing
  • Upload audio → get structured tags
  • Positioned more toward professional music libraries and distributors
  • Pricing not indie-friendly — likely enterprise tiers
  • Less focused on similarity search vs. Cyanite
Contact for pricing (likely $$)
For Simi: Excellent tag quality but probably over-priced for solo dev stage. Worth revisiting once Simi is generating revenue or needs catalog-level tagging.
MusicAtlas
Newer

Open music search and discovery infrastructure. Supports track-to-track similarity, mood/scene/lyrical search, and catalog matching. Pitched at technical founders building discovery and recommendation features.

  • Track-to-track similarity (up to 20 results per query)
  • Search by mood, scene, lyrical idea, or sonic reference
  • Audio traits, genre, platform metadata, possible influences
  • Designed for "more like this" recommendation flows
  • Pricing not publicly listed — requires API key request
  • Catalog coverage unclear vs. Spotify's 100M+ tracks
Request API key at musicatlas.ai/developer/request-key
For Simi: The "search by scene or mood" capability is very relevant. Worth requesting an API key and testing — could complement Cyanite well for the discovery layer.

Category 3 — Free & Low-Cost Metadata APIs

Great for bootstrapping, layering additional signals, or supplementing more expensive APIs. Lower precision than AI-based tools but free to start.

Last.fm API
Free Already in Simi

One of the oldest and most comprehensive free music metadata APIs. Community-driven tags give surprisingly rich mood/genre data. Simi is already using this — key to understand what it can and can't do.

  • Free, up to 5 requests/second
  • Similar tracks and similar artists endpoints
  • Top tags per artist/track (mood, genre, decade — community-generated)
  • Artist bios, album data, listening counts
  • Tag similarity search
  • Tags are community-driven, not AI — inconsistent precision
  • No quantitative scores (no valence 0–1 scale like Spotify)
  • Coverage gaps for newer/indie artists
Free — no credit card, generous rate limits
For Simi: Already integrated. Best used as a supplementary signal layer — especially for the "Same Genre / Same Mood" tags in your list view. Not sufficient alone for emotional imprint matching.
Soundcharts Audio Features API
1,000 free requests Paid tiers

Provides the full Spotify-equivalent audio features suite — without needing to upload audio. Look up tracks by ISRC or Spotify/Apple Music ID. No credit card required to start.

  • BPM, key, time signature, energy, valence, danceability, acousticness, instrumentalness, speechiness, liveness, loudness
  • No audio upload — use ISRC or platform track ID
  • 1,000 free requests, no credit card required
  • Paid plans billed monthly
  • Covers existing catalog tracks only (no custom audio analysis)
1,000 free requests → monthly paid plans
For Simi: Strong pragmatic choice for an early-stage MVP — gives Spotify-quality features for catalog tracks with zero friction to start. Pair with Last.fm tags for a free-tier combination that covers most use cases.
AudD
300 free/month $2–5/1k

Primarily a music recognition (fingerprinting) API. Useful if you need to identify audio from a clip rather than look up known tracks. Less relevant for mood/energy analysis.

  • Audio fingerprinting from file, stream, or URL
  • Returns title, artist, album, ISRC, UPC
  • 160M track database
  • Enterprise endpoint supports full-length files with timestamps
  • Recognition, not analysis — no mood/energy scores
  • 300 free requests/month is low for production use
300 free/month → $2–5 per 1,000 requests
For Simi: Useful if you add a "hum or sing to find similar songs" feature. Not useful for the core audio features use case.
iTunes Search API
Completely free

Lee Martin's recommended alternative for basic music search. No authentication required, returns ISRCs which can be used to cross-reference other APIs. Also provides 30-second audio previews (which Spotify deprecated).

  • No authentication whatsoever
  • Track, album, artist metadata
  • ISRC included — cross-reference with other APIs
  • 30-second audio previews still available
  • No audio features (energy, mood, valence)
  • Metadata only — use as a search/lookup layer
Free — no key required
For Simi: Great as a search fallback when Spotify returns no results. The free preview audio could be useful for a "preview before saving" feature. Use ISRC to cross-reference with Soundcharts or Cyanite.

Category 4 — Open Source / Self-Hosted

Essentia (MTG/UPF)
Open Source Free (self-hosted)

Industry-standard open-source C++ audio analysis library from the Music Technology Group at UPF Barcelona. The same engine that powered AcousticBrainz. If you run it yourself, there are zero API costs.

  • BPM, key, energy, loudness, danceability
  • Mood models (happy/sad, aggressive/relaxed, etc.) via deep learning
  • Tonal, spectral, and temporal descriptors
  • Python and JavaScript (Essentia.js) bindings
  • Partial iOS support (cross-compiled)
  • AGPLv3 license (or commercial license on request)
  • Steep integration effort — especially for Swift/iOS on-device
  • Requires server infrastructure if running server-side
  • No built-in similarity search — you build that layer yourself
$0 — self-hosted, but engineering cost is real
For Simi: Best long-term option if you want full control and zero per-query cost at scale. Realistically, this is a V2 or V3 investment — the engineering lift is significant for iOS. Consider a server-side microservice wrapping Essentia + Python.
⚠️ AcousticBrainz — Archived AcousticBrainz (also built on Essentia) stopped collecting data in 2022. The existing dataset is still downloadable but there's no live API. Useful as a reference dataset but not for production use.

Recommended Stack for Simi

A layered approach — each tier adds depth while managing cost. You don't need all of these at once; start with Tier 1+2 and layer up as you grow.

1

Cyanite.io — Emotional intelligence core

For Simi's "emotional imprint" philosophy, this is the best fit. It's the only API built around the emotional content of music — not just technical features. Use it for the vibe-matching layer. Free test tier lets you validate before committing.

2

Musicae.io Extended Audio Features (via RapidAPI) — Spotify drop-in

Restores /audio-features and /recommendations with zero code changes. Use this to keep your existing data model working while you evaluate deeper emotional APIs. The DJ Analysis API's extra scores (hype, chill, groove) are a bonus that directly serve Simi's vibe concept.

3

Soundcharts Audio Features API — Free catalog lookup

1,000 free requests with no credit card. Look up any catalog track by ISRC. Use as a fallback or to pre-cache features for the most popular tracks your users search. Reduces calls to paid APIs.

4

Last.fm API — Free similarity & tags

Already in Simi. Fully free. Continue using for the "Same Genre / Same Mood" tags and similar artist graph. Layer on top of AI-scored results for richer reason strings shown to users.

5

iTunes Search API — Zero-auth metadata fallback

Use for track lookup when Spotify search is unavailable or rate-limited. ISRCs from iTunes let you cross-reference with Soundcharts and Cyanite. 30-second preview clips are a potential UX win.

🎯 Concrete Next Steps for Simi

  1. Sign up for Cyanite.io free test tier and run 10–20 tracks through their API Compare their emotional tags against what Simi currently shows. Look specifically at mood/arousal quadrant outputs.
  2. Get a RapidAPI key and test Musicae.io's Extended Audio Features endpoint Test /audio-features/{spotify_id} with a handful of track IDs. Confirm the response format matches Spotify's exactly.
  3. Sign up for Soundcharts API (no credit card) and test audio feature lookup by ISRC Use iTunes Search API to get ISRCs for free, then feed them into Soundcharts. This gives you Spotify-quality features for free up to 1,000 requests.
  4. For the Cyanite innovator program application — answer "B) < 10,000" audios Honest for MVP scale. If accepted, Cyanite's program may include extended API access that reduces cost concerns significantly.
  5. Reduce hard dependency on Spotify as input source Consider accepting Apple Music links, SoundCloud links, and YouTube Music links in addition to Spotify. iTunes Search API + ISRC cross-referencing makes this feasible without much overhead.
